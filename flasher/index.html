AFTER INSTALLATION

Make it yours.

On the controller, open Wi-Fi Setup. Join the network shown on its display, then open 192.168.4.1 to edit your MIDI actions.

Controller isn’t detected?

Try another USB data cable. Hold BOOT, tap RESET, then release BOOT and connect again. The serial port may change when entering download mode. Select the new port. If the controller stays in download mode after installation, tap RESET once.

Will my settings be kept?

For this project’s existing partition layout, leave Erase device unchecked. The installer writes around the saved-settings region. Export a JSON backup from the Wi-Fi editor first. If replacing unrelated firmware or recovering corrupt settings, select Erase device; this removes all saved mappings, calibration and settings.

Can I use my iPad?

Use a desktop browser with Web Serial for USB installation. After installation, use your iPad for BLE MIDI and the controller’s Wi-Fi configuration editor.
